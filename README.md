### Simple Calculator - Production Web Application

Repository: [owino-brian/Simple-Calculator](https://github.com/owino-brian/Simple-Calculator)

A professionally-engineered web-based calculator demonstrating secure coding practices, accessibility compliance, and production-grade implementation standards.

**Technical Implementation:**
- Tokenizer-based expression parsing without eval() function (eliminates code injection vulnerability)
- Shunting-yard algorithm implementation for operator precedence handling
- Reverse Polish Notation (RPN) evaluation engine
- Full operator support: addition, subtraction, multiplication, division, modulo
- Unary minus, percentage operations, and parentheses grouping
- Keyboard input handling for numerical entry and operator commands

**Accessibility Features:**
- ARIA live regions for screen reader compatibility
- Descriptive aria-label attributes on all interactive elements
- Keyboard-navigable interface with focus state indicators
- Readonly input field preventing arbitrary typing
- High-contrast color scheme meeting WCAG standards

**Security Architecture:**
- No usage of JavaScript eval() function
- Input length validation preventing buffer overflow scenarios
- Safe mathematical expression evaluation through RPN conversion
- Protection against arbitrary code execution

**Stack:** HTML, CSS, JavaScript

**Deployment:** Single-file architecture enabling rapid deployment
